# GTCEu GregBlock Edition

GregTech CEu Modern for the GregBlock Minecraft 1.20.1 Forge modpack. This project builds on the [Star Technology fork](https://github.com/StarT-Dev-Team/GTM-StarT-Fork) of [GregTech CEu Modern](https://github.com/GregTechCEu/GregTech-Modern) and retains their commit history.

The initial GregBlock build, `7.5.3.7`, includes selective backports for Jade, EMI, AE2, ore and fluid compatibility, and parallel recipe viewer indexing.

[Issues](https://github.com/LeandroHunter/GTCEu-GregBlock-Edition/issues) · [Pull requests](https://github.com/LeandroHunter/GTCEu-GregBlock-Edition/pulls) · [Contribution guide](CONTRIBUTING.md)

## Build

Use JDK 17. Run `./gradlew reobfJar` on Linux or macOS, or `.\gradlew.bat reobfJar` on Windows. Find the distributable JAR in `build/libs`.

## Contribute

Fork this repository and open a pull request against `main`. Include what changed, the upstream commit for any backport, and how you tested it.
